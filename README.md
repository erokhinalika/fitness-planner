# Pulse Plan для Анжелики

Персональный фитнес-планер на React + Vite + TypeScript + Tailwind.

Проект рассчитан на использование с телефона во время домашних тренировок: календарь, отметки выполнения, библиотека упражнений с GIF/видео-блоками, фото-прогресс, замеры, питание, покупки, плейлисты и экспорт/импорт прогресса.

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm run build
npm run typecheck
```

## Деплой на Vercel

1. Залей проект в GitHub.
2. В Vercel выбери `Add New Project`.
3. Framework Preset: `Vite`.
4. Build command: `npm run build`.
5. Output directory: `dist`.

## Данные

Все персональные данные хранятся локально в браузере через `localStorage`:

- отметки тренировок;
- замеры;
- фото-прогресс;
- чекбоксы покупок;
- добавленные плейлисты.

Кнопка `Export Progress` скачивает JSON-бэкап. `Import Progress` восстанавливает данные из такого JSON.

## Видео/GIF упражнений

В библиотеке упражнений используются внешние GIF-ссылки на страницы техники. Если внешний GIF не загрузится, сайт показывает встроенную анимированную технику-заглушку, чтобы карточка упражнения не была пустой.

## Яндекс Музыка

У Яндекс Музыки нет стабильного публичного iframe-плеера, который можно надёжно встроить как полноценный web player. Поэтому в сайте сделан практичный вариант: карточки плейлистов с быстрым открытием ссылки в приложении или браузере. Можно вставлять свои ссылки на плейлисты из Яндекс Музыки.
